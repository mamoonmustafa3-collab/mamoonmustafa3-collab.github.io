# Mamoon Fares | Digital Marketing Portfolio

Personal portfolio website, prepared for GitHub Pages.

## Publish
1. Create a **public** GitHub repository named `mamoonmustafa3-collab.github.io`.
2. Upload the **contents** of this folder to the repository root (not the folder itself).
3. In **Settings → Pages**, set **Source** to **Deploy from a branch**; **Branch** to **main**, **/(root)**, then click **Save**.
4. After deployment, visit https://mamoonmustafa3-collab.github.io/

No build step is required. Fonts are stored locally under `fonts/`. The downloadable CV is at `assets/Mamoon_Fares_CV.pdf`.

**Privacy:** The PDF CV and any contact details it includes will be publicly accessible on the internet once published.
